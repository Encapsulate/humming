# V100 / SM70 baseline

This branch provides a correct, portable baseline for a Tesla V100:

- Humming's existing quantization and packing kernels run as JIT CUDA kernels.
- Dense FP16-activation layers with quantized weights use an FP16 dequantized
  cache and PyTorch/cuBLAS for GEMM.
- The dequantized cache is built once by `transform()`, not once per forward.

The native Humming SM75+ GEMM is not used on Volta because it requires
`ldmatrix` and `m16n8k16` instructions that SM70 does not implement.  MoE,
FP8/INT8 activations, and the native custom GEMM remain unsupported on SM70.

Use a CUDA runtime whose FP16 cuBLAS path supports SM70.  The fallback was
verified with PyTorch 2.5/CUDA 12.1.  Install Humming's standard dependencies
in that same environment; no secondary inference environment is required:

```bash
python -m pip install -e .
python your_program.py
```

If FP16 GEMM fails in a particular PyTorch/CUDA pairing, use a supported
SM70-compatible runtime rather than changing Humming's numerical code.
